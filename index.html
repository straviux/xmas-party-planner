Find your name

Type any part of your name or nickname — even a nickname the host added for you. Then tap your exact entry. You don't type a name to reveal, you pick it, so spelling can't mismatch.

Is this you?

This name has a private PIN. Enter the PIN the host gave you privately.

🎁 You are buying for:

Write it down now. This screen won't show it again, and rescanning the QR with your name will only say “already revealed”.

📝 Wishlists

Post what you'd like, so your Secret Santa giver can check your list after they reveal you. Lists are public by name — that's the point. Only you can add or delete your own items.

Step 1 — who are you? Search and tap your exact name (same searchable list as Secret Santa).

Everyone's wishlists

Found something you'll buy for someone? Tap Reserve — it will show as Reserved to everyone, but never say who reserved it, so gifts don't duplicate and the giver stays secret. Tap again to unreserve it (only you can unreserve your own reservation).

🗳️ Christmas theme poll

One vote per guest. You can change your vote until the host closes the poll. Results show counts only — never who voted for what.

Host setup

Add each guest once. Name is what guests will see. Nickname shows next to it. Aliases are extra searchable spellings — e.g. a short name, maiden name, or a name guests actually call them. Guests pick from this list, so they never have to spell it exactly right.

The draw is a derangement: nobody gets themselves. The host dashboard shows only who has / hasn't claimed — never who got whom.

Host dashboard

Enter your host PIN to see claimed status. Recipients are never shown here.

🗳️ Theme poll setup (host)

Create the theme poll guests vote on. Example themes: Ugly Sweater, Winter Wonderland, Pajama Party, Red & Gold.

How it stops rescans: the server (or this device, in local mode) marks a name claimed the moment it reveals. A second scan + the same name only gets “already revealed”, with no recipient shown.
